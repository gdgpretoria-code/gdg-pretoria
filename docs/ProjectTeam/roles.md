# Roles

Current roles we have defined.

## Product manager

A product manager drives the success of a website by acting as the bridge between business goals, user needs, and tech execution. They define the vision, prioritize website features, manage the roadmap, and work closely with designers, developers, and marketers from launch to ongoing optimization.

### Strategy and Vision

* **Define the Goal:** Set the core purpose of the website and align it with overall business objectives.
* **Research Users:** Analyze target audiences, competitor websites, and user feedback.
* **Build Roadmaps:** Outline milestones, feature releases, and timelines using a clear, phased approach.

### Execution and Collaboration

* **Write Requirements:** Translate ideas and user needs into clear feature specs or user stories for developers.
* **Prioritize Tasks:** Manage the feature backlog, deciding what gets built now versus later.
* **Coordinate Teams:** Work hand-in-hand with UI/UX designers and software engineers to ensure the site is intuitive and functional.

### Launch and Analysis

* **Manage Release:** Coordinate the rollout, testing phases, and marketing integration.
* **Track Metrics:** Monitor performance indicators like traffic, bounce rates, and conversion rates post-launch.
* **Iterate:** Use data and user feedback to continuously improve the website experience.

## Project Managers

### Scope and Schedule Management

* **Build Timeline:** Create detailed project schedules with clear milestones for your design and development phases.
* **Define Scope:** Document exactly what is included in the project to prevent feature creep.
* **Track Velocity:** Monitor daily development progress against your target launch date.

### Team and Resource Coordination

* **Assign Tasks:** Allocate specific website components (like frontend, backend, or API integrations) to individual developers or designers.
* **Run Meetings:** Facilitate daily stand-ups or weekly syncs to keep the entire team aligned.
* **Clear Roadblocks:** Resolve workflow dependencies and tech constraints that slow down the development team.

### Risk and Delivery Control

* **Manage Risks:** Identify potential tech bottlenecks early, such as API downtime or testing delays.
* **Enforce Quality:** Coordinate with testers to make sure bugs are logged and fixed before rollout.
* **Report Status:** Keep community organizers and key stakeholders updated on delivery progress and launch readiness

## UI/UX designer

A UI/UX designer creates the look, feel, and navigation of the GDG Pretoria website. Their role is to ensure the platform is visually appealing, easy for community members to navigate, and aligned with Google's design standards.

### User Experience (UX) Design

* **Map Journeys:** Design user flows to ensure developers can find events and register in as few clicks as possible.
* **Build Wireframes:** Create low-fidelity structural blueprints of pages to plan content placement before coding.
* **Prototyping:** Build interactive mockups so the team can test the site layout and navigation beforehand

### User Interface (UI) Design

* **Apply Brand Standards:** Implement Google’s material design guidelines, ensuring the correct GDG Pretoria typography, layout rules, and icon styles.
* **Design Visual Assets:** Create custom graphics, buttons, banners, and dark/light mode interfaces.
* **Ensure Accessibility:** Design high-contrast layouts and readable text scales that work for everyone, including users with visual impairments.

### Developer Handover

* **Prepare Style Guides:** Deliver a component library (buttons, forms, navigation bars) so developers can easily reuse UI elements.
* **Specify Layouts:** Provide responsive designs showing exactly how the layout changes from desktop to mobile screens.
* **Inspect Execution:** Review frontend builds during sprints to check that the coded site matches the original designs.

## Frontend Developer

A frontend developer translates the designer’s layouts into clean, interactive code that users see and interact with in their web browsers. They bridge the gap between visual design and the backend logic, ensuring the GDG Pretoria website is fast, responsive, and functional.

### UI Coding and Responsive Layouts

* **Convert Designs:** Transform design mockups (from tools like Figma) into semantic HTML, CSS, and JavaScript. We will be using Angular.
* **Build Responsively:** Ensure the community portal layout adapts perfectly to mobile phones, tablets, and desktop monitors.
* **Animate Interactions:** Code smooth transitions, hover states, and dynamic elements like dropdown menus or pop-ups.

### API Integration and Dynamic Content

* **Fetch Data:** Connect the frontend user interface to backend data pipelines or third-party event calendars.
* **Display Events:** Write code to dynamically pull, filter, and render live event schedules, RSVP numbers, and speaker profiles.
* **Manage State:** Control how data changes on the screen in real-time as users interact with forms, search bars, or user dashboards


### Performance and Quality Assurance

* **Optimize Loading:** Compress images, minify code scripts, and leverage caching so the webpage loads instantly on slow mobile networks.
* **Cross-Browser Testing:** Ensure the site functions flawlessly across Google Chrome, Safari, Firefox, and Microsoft Edge.
* **Maintain Accessibility:** Write clean, semantic code that screen readers can interpret, adhering to web accessibility guidelines (WCAG)


## Backend Developers

A backend developer builds and maintains the invisible engine of the GDG Pretoria website. They handle the server logic, database management, and API integrations that power the frontend, ensuring the platform is secure, scalable, and stable.

### Architecture and Database Management

* **Design Databases:** Structure databases to store user profiles, organizer records, and event information.
* **Manage Data Flow:** Write optimized queries to fetch, update, and organize data without causing server lag.
* **Ensure Integrity:** Create validation rules so that bad data cannot corrupt the system.


### API Development and Third-Party Integration

* **Build Custom APIs:** Create secure endpoints that send data (like event lists or attendee names) directly to the frontend.
* **Integrate Systems:** Connect the website to external systems like Google Dev Community APIs, email engines, or calendar feeds.
* **Process Automation:** Code automated scripts to trigger confirmation emails or slack notifications whenever a user RSVPs.

### Security, Performance, and DevOps

* **Secure the App:** Implement user authentication (like Google OAuth Sign-in), encrypt passwords, and protect against web attacks.
* **Optimize Servers:** Set up server caching and optimize scripts to handle high traffic spikes when major event registrations open.
* **Manage Hosting:** Deploy the backend application to cloud servers (such as Google Cloud Platform or Firebase) and monitor uptime

## Quality Assurance (QA) Engineer / Tester

* **Find Bugs:** Tests every feature, link, form, and button to ensure the website does not break.
* **Test Devices:** Verifies the site works on different mobile phones (Android/iOS) and web browsers.
* **Simulate Users:** Inputs wrong data into forms (like invalid emails) to make sure the site handles errors gracefully.

## Content Writer / Editor

* **Write Text:** Drafts the copy for the homepage, event descriptions, speaker bios, and "About Us" pages.
* **Maintain Tone:** Ensures the language is welcoming, professional, and fits the Google Developer Groups community style.
* **SEO Optimization:** Writes headings and meta descriptions to help the site rank well on Google search.

## DevOps Engineer / Cloud Architect

* **Deploy Code:** Sets up automated pipelines (CI/CD) so frontend and backend code moves smoothly to production.
* **Cloud Hosting:** Manages infrastructure, usually on platforms like Google Cloud Platform (GCP) or Firebase.
* **Security & Backups:** Sets up SSL certificates for secure browsing (https://) and schedules automated database backups

## Cybersecurity Analyst (Security Lead)

* **Protect Data:** Ensures user login data (like Google OAuth tokens) and attendee lists are stored securely and cannot be leaked.
* **Vulnerability Scanning:** Checks the codebase and servers for common security flaws or outdated code libraries.
